# Ashes and Crowns — project memory

3D open-world medieval permadeath simulation. England, 1135, The Anarchy. Zero magic. Grim historical realism.
Design source of truth: `docs/GDD.md`. Decisions log: `docs/DECISIONS.md`. Read both before changing anything.

## Engine and versions
- Unity **6000.0 LTS** (`UnityProject/ProjectSettings/ProjectVersion.txt` says 6000.0.50f1; any 6000.0.x works — Unity Hub will offer to switch). URP 17, Input System 1.11, Burst 1.8, Collections 2.5, Mathematics 1.3, UI Toolkit, Unity Test Framework 1.4.
- The Unity project lives in `UnityProject/` (repo root holds docs and tooling). Target: Windows + macOS desktop (Steam later). No browser build. No backend.
- .NET 8 SDK is used **only** for `Tools/dotnet-tests` (runs the Sim tests outside Unity).


## Assembly dependency direction (never create cycles)
`Sim` ← `Save` ← `Battle` ← `Combat` ← `UI` ← `Game` ← `Editor`. `Save` (engine-free: RunState, codec, store) references `Sim` only; `Trades` references `Sim` only (for now).
Sim must never reference UnityEngine. Battle must never reference Game.

## Coding standards
- No magic numbers: every tunable goes in `Assets/Data/balance.json` and the matching `Sim.Balance` class. Add a `BalanceValidator` check for new fields when sensible.
- Deterministic: all randomness through `Sim.DeterministicRng` (seeded per run, `Fork(streamId)` per system). Never `UnityEngine.Random` or `System.Random` in gameplay.
- Battle and anything per-frame: zero managed allocations (no LINQ, no closures, no string concat in Update; cache strings, update text at low cadence). Soldiers are structure-of-arrays NativeArrays driven by Burst jobs; rendering via `Graphics.RenderMeshInstanced`.
- One MonoBehaviour per file, file named after the class. Public fields only for inspector wiring; otherwise properties.
- Scenes are built by code (`Phase0SceneBuilder`, `Phase1SceneBuilder`, shared helpers in `SceneKit`), never hand-edited; change the builder and rebuild via menu `Ashes and Crowns > Rebuild > ...`. Generated assets live in `Assets/Generated` and `Assets/Art/Palette` and are not committed; textures are written as PNG and imported (a Texture2D saved as .asset renders white).
- Geography comes from `Assets/Data/england_coast.json` + `world.json` (normalized 0..1 coordinates, x east, z north); `EnglandTerrainBuilder` rasterises it. World scale: 8192 m terrain = 673 km; villages and battles are 1:1.
- Art direction: desaturated, mud/iron/blood/cold light; URP Lit with `_BaseColor`; everything through the palette materials in `Assets/Art/Palette`. No cartoon colours.
- Tests first for Sim rules and the save system (TDD). PlayMode tests for the death flow and battle smoke. The Save assembly must stay engine-free so `dotnet test Tools/dotnet-tests` covers it.
- Permadeath invariants: the save is deleted synchronously in `SaveManager.OnDied` before the death screen; nothing may write a save after `_dead` is set; every scene gets a SaveManager wired by its builder.
- Commit at the end of each milestone. Never force-push or rewrite history. Push only when the user says so.

## Running tests and builds
- Sim tests outside Unity: `dotnet test Tools/dotnet-tests` (needs .NET 8 SDK). Same test files Unity runs.
- In Unity: Window > General > Test Runner, or `unity test UnityProject --mode EditMode` / `--mode PlayMode` (Unity CLI).
- Headless project setup: `unity run UnityProject -- -executeMethod AshesAndCrowns.EditorTools.ProjectBootstrap.SetupHeadless`
- Headless build: `unity build UnityProject --target StandaloneWindows64 --execute-method AshesAndCrowns.EditorTools.BatchBuild.BuildWindows` (also `BuildMac`, `BuildLinux`).
- First open: Unity Hub > Add > `UnityProject/`. On load, `ProjectBootstrap` creates the URP asset, enables the Input System (one restart needed), creates UI Toolkit panel settings and builds `Assets/Scenes/Phase0_Battlefield.unity`.
